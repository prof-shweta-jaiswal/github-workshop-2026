
# GitHub Workshop 2026

Welcome to the GitHub Workshop 🚀

## Objective

Students will learn:

* Forking a repository
* Cloning a repository
* Creating branches
* Making commits
* Pushing code
* Creating Pull Requests

---

## Contribution Steps

### 1. Fork the Repository

Click on the **Fork** button at the top right corner.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/github-workshop-2026.git
```

### 3. Create a New Branch

```bash
git checkout -b add-your-name
```

### 4. Add Your Contribution

Create a file inside `students/`

Example:

```bash
students/rahul.md
```

Add details like:

```md
# Rahul

- College: XYZ College
- Skills: Java, GitHub
- Interest: Open Source
```

### 5. Commit Changes

```bash
git add .
git commit -m "Added Rahul profile"
```

### 6. Push Changes

```bash
git push origin add-your-name
```

### 7. Create Pull Request

Open GitHub and click:

* Compare & Pull Request
* Create Pull Request

Happy Contributing 🎉
